# Student Services Portal

## Project Description

A professional TypeScript project that serves as the foundation of a University Student Services Portal. This repository establishes a modern development workflow using TypeScript, Git, GitHub, ESLint, Prettier, and responsible AI-assisted development.

## Requirements

- Node.js
- npm
- TypeScript
- ESLint
- Prettier
- Git

## Installation Instructions

Install the project dependencies:

```bash
npm install
```

## How to Run the Project

Build the TypeScript project:

```bash
npm run build
```

Run the project:

```bash
npm start
```

## How to Run Linting

Check the TypeScript code using ESLint:

```bash
npm run lint
```

## How to Format Code

Format the project files using Prettier:

```bash
npm run format
```

## Development Workflow

1. Create or select a GitHub Issue for the feature.
2. Create a feature branch from the main branch.
3. Develop and test the feature locally.
4. Run ESLint and Prettier before committing.
5. Commit the changes using a meaningful commit message.
6. Push the feature branch to GitHub.
7. Open a Pull Request.
8. Review and test the changes before merging into main.

## AI Usage Policy

AI coding assistants may be used to suggest code, explain concepts, and help identify possible improvements. AI-generated code should not be accepted without review. All AI recommendations must be understood, tested, and verified before they are included in the project.
